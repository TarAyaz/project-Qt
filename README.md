# My Personal Organizer

## Сборка

```bash
pyinstaller build.spec
```

## Запуск

- Linux

```bash
./dist/MyOrganizer
# или
./dist/MyOrganizer/MyOrganizer
```

- Windows

```bash
dist\MyOrganizer.exe
# или
dist\MyOrganizer\MyOrganizer.exe
```

- MacOS

```bash
./dist/MyOrganizer
# или
./dist/MyOrganizer.app/Contents/MacOS/MyOrganizer
```
